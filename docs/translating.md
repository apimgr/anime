# Translation guide

The current server-rendered interface, API responses, CLI, and documentation are provided in English. The project does not currently ship locale catalogs or a translation workflow. Do not create or advertise translated strings until an application localization feature is implemented.

When contributing a translation, open an issue or pull request describing the proposed scope and include the source text, target language, and any context needed to preserve technical meaning. Keep API field names, route paths, command names, and configuration keys unchanged.
