Privacy Policy

How Anime Quotes handles requests, browser preferences, and reports.

Summary

Build: {{.BuildDate}}

  • Quote data is embedded in the application.
  • {{if .DataSold}}Visitor data may be shared with or sold to third parties as described below.{{else}}We do not sell visitor data.{{end}}
  • Search terms may appear in request logs.
  • Theme, language, and consent choices stay in first-party browser cookies.

Cookie policy

  • Essential: {{.EssentialCookieDescription}}
  • Preferences: {{.PreferenceCookieDescription}}
  • Analytics: {{.AnalyticsCookieDescription}}
  • Consent: stores the visitor's cookie-consent choice in a first-party cookie.

Manage cookie choices on the preferences page.

Data collection

Search terms are sent as URL query parameters so the service can filter quotes. The server logs request method, URI, and duration; search terms may therefore appear in logged request URIs. The request address is used for rate limiting and abuse prevention.

Visitors who submit a report provide the name, reply address, and report content needed to review and respond to it.

Data usage

Request data supports quote search, service operation, and abuse prevention. Report details are used to review and respond to the visitor's request. {{if .DataSold}}Visitor data may be shared with or sold to third parties as described by the service operator.{{else}}Visitor data is not sold or used for targeted advertising.{{end}}

Data security

Application secrets are stored with restricted file permissions. Security reports are protected at rest when stored. Operators should serve public traffic over HTTPS and restrict access to application data and logs.

Data storage

The quote collection is embedded in the application binary. {{if .DataStoredOnServer}}Application data is stored on this server.{{else}}Some application data is stored outside this server.{{end}} Operational secrets and short-lived form challenges are kept in the configured local database. Optional release discovery and updates use GitHub Releases.

Data retention

Preference values remain in the visitor's browser and are not stored as profiles. {{.PrivacyRetention}} Report retention follows the configured reporting process.

Third parties

Serving quotes and checking health do not contact external services. The explicit update command and CLI release discovery contact GitHub Releases.
